# 마음이 방긋 · 한글날 함께 놀아요

러시아어를 사용하는 초등학교 저학년 아이들과 함께하는 한국어·러시아어 마음 열기 퀴즈입니다.
교사가 큰 화면을 보여 주며 약 20명과 7–10분 동안 진행합니다.

## 실행

`dist/index.html`을 브라우저에서 열면 바로 사용할 수 있습니다. 설치나 빌드는 필요하지 않습니다.
웹 서버를 사용할 경우 저장소 폴더에서 다음 명령을 실행한 후 http://localhost:8000 으로 접속합니다.

```sh
python3 -m http.server 8000 --directory dist
```

폰트는 Google Fonts에서 불러오며, 연결이 없으면 시스템 글꼴로 표시됩니다.

## 활동

1. 오늘 내 기분: 기쁜 얼굴·졸린 얼굴·설레는 얼굴
2. 어떤 동물일까?: 교사의 시범을 보고 동물 고르기
3. 함께 인사해요: 손 흔들기·박수·하트
4. 선생님에게 알려줘요: 아이들에게 러시아어 동물 이름 배우기
5. 오늘 무엇을 만들까요?: 책을 고르면 함께 책 만들기로 마무리

점수와 탈락은 없으며 러시아어, 그림 가리키기, 몸짓 모두 참여로 인정합니다.
화면 아래에서 교사용 진행 안내를 펼칠 수 있습니다.
이전·다음·처음부터 버튼, 진행 표시, 모바일 화면을 지원합니다.
